# Typography

A typography page defines the visual system for text across the product.

* **Font Families:** Primary and secondary typefaces used for headings, body text, labels, and UI elements.
* **Font Sizes:** A consistent scale for headings, body copy, captions, and supporting text.
* **Font Weights:** Defines hierarchy and emphasis, such as Regular, Medium, Semibold, and Bold.
* **Line Heights:** Controls readability and vertical rhythm for different text styles.
* **Spacing:** Establishes consistent spacing between letters, words, lines, and text elements.
* **Hierarchy:** Ensures headings, body text, and supporting content are visually distinct and easy to scan.
* **Consistency:** Provides reusable typography styles to maintain a cohesive experience across all pages.
